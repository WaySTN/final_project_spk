## 2. Panduan Pengambilan Ulang di Produksi (Setelah Deploy Disetujui)

Apabila seluruh migrasi Supabase produksi dan deployment Vercel pada `https://finalprojectspk.vercel.app/` telah disetujui dan dijalankan, tangkapan layar final versi produksi dapat diambil ulang secara manual dengan membuka rute pada kolom **Rute / Aksi** di atas menggunakan browser desktop (`1440×960`) dengan catatan:
- Pastikan mode akun admin tidak menampilkan email pribadi pada laporan publik (potong/samarkan panel akun pojok kiri bawah apabila akun Supabase menggunakan email personal).
- Pastikan tidak mengambil tangkapan layar halaman `/admin/responden` yang memuat tabel jawaban individual untuk lampiran publik.
